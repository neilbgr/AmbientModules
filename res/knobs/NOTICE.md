PAN/VOL knob artwork adapted from Valley Audio's "Rogan Med Small White" knob
— the same knob Plateau uses for its "Dry level"/"Wet level" controls
(ValleyRackFree, GPL-3.0-or-later, © Dale Johnson / Valley Audio Soft —
https://github.com/ValleyAudio/ValleyRackFree).

- `Rogan1PSMedSmall-bg.svg`, `Rogan1PSWhiteMedSmall.svg`,
  `Rogan1PSWhiteMedSmall-fg.svg`: copied unmodified. The knob's dark knurled
  rim + position-indicator tab live in `Rogan1PSWhiteMedSmall.svg` (shared by
  both colors, unmodified, so the indicator stays the same regardless of face
  color); the round face itself is the `.st2` disc in `-fg.svg`.
- `Rogan1PSBlackMedSmall-fg.svg`: derived from `Rogan1PSWhiteMedSmall-fg.svg`
  by recoloring only that face disc (`#f2f2f2` -> `#141414`); the shared
  white-to-grey gloss gradient underneath and the drop shadow are unchanged,
  giving a black face with the same bright bezel ring as the white knob.
- `Rogan1PSRedSmall.svg`, `Rogan1PSSmall-bg.svg`, `Rogan1PSRedSmall-fg.svg`:
  copied unmodified from Valley's smaller "Small" size tier (~5.2mm vs the
  ~8.4mm "MedSmall" tier above) — the same knob Plateau uses for its
  "Predelay" control. Used by LunarJoystick's range-selector knob.
